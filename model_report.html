Model Evaluation Report

This report summarizes the performance of the sleep-stage classification models using ROC curves and confusion matrices. The ROC curve evaluates discrimination across thresholds; the matrix shows correct and incorrect final predictions.

Experiment Summary

  • Training patients: 1, 2, 3, 4, 5, 6, 7.
  • Test patients: 8, 9, 10.
  • Only epochs with matching labels from both annotators are retained.
  • Artifact detection threshold: 60 × signal standard deviation.
  • Epochs evaluated: 2657 for the multiclass model, 1220 for the binary model, and 2657 for the combined model.
  • Combined-model confidence threshold: 0.95; 1336 of 2657 epochs were accepted (50.3% coverage).
